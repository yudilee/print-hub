Quick Setup Guide
1

Configure Print Hub Server

Go to Print Hub ➔ Configuration ➔ Settings. Enter your Print Hub Base URL and API Key (X-API-Key).

2

Test Server Connection

Click the "🔗 Test Connection" button. Odoo will verify API credentials and display the number of online hardware agents.

3

Sync Discovered Hardware

Click "🔄 Sync Printers Now" to import all local printers, paper profiles, and printer pools discovered across your branch network.

4

Set Up Document Routing Rules

Navigate to Configuration ➔ Document Routing Rules to map specific reports (e.g. Surat Jalan) to designated physical printers or virtual queues.

Developer Integration (`print.hub.mixin`)

Enable background printing on any custom Odoo model in just 3 lines of code:

# Inherit the mixin in your model class class CustomDocument(models.Model): _name = 'custom.document' _inherit = ['custom.document', 'print.hub.mixin'] def action_print_to_branch_printer(self): self.ensure_one() # Dispatches QWeb PDF directly to the resolved printer return self.print_via_hub( report_name='my_module.report_custom_document', options={'copies': 2} )
